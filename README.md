# Netflix India Landing Page Clone 🎬

A modern, responsive frontend clone of the **Netflix India** landing page built with pure **HTML5** and **Vanilla CSS3**. This project replicates Netflix's user interface, including promotional banners, trending carousels, feature highlights, FAQs, and subscription call-to-actions.

---

## ✨ Features

- **Top Promotional Banner**: Eye-catching promotional notification bar with gradient styling.
- **Hero / Showcase Section**: High-resolution dark-overlay hero backdrop with responsive subscription email capture.
- **Trending Now Section**: Styled numbered cards showcasing top trending shows and movies with smooth hover zoom animations.
- **Value Proposition Cards**: Modern gradient-styled feature cards with icons ("Enjoy on TV", "Download shows", "Watch everywhere", "Kids profiles").
- **FAQ Accordion Section**: Interactive-ready layout for frequently asked questions with modern dark-mode aesthetic.
- **Footer**: Multi-column quick links, contact helpline, and language selector matching Netflix's regional layout.
- **Pure Vanilla Codebase**: Zero external dependencies or frameworks—lightweight and fast loading.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup structuring all sections, forms, and assets.
- **CSS3**: Modern CSS using Flexbox, CSS gradients, hover animations, custom text strokes, and clean typography.

## 🚀 Getting Started

No build tools, package managers, or local servers are required!

### 1. Clone or Download the Repository
```bash
git clone https://github.com/your-username/netflix-clone.git
cd netflix-clone
```

### 2. Open in Browser
Simply open the `index.html` file in your preferred browser:
- **macOS**: `open index.html`
- **Windows**: `start index.html`
- **Linux**: `xdg-open index.html`

Alternatively, use the **Live Server** extension in VS Code.
